###### 2.2.1新建飞行计划

**创建流程**：先选空域（附近起降点基于GPS定位 + 最近搜索 + 搜索框），再填写详细表单。GPS定位拒绝授权时降级为只展示最近搜索和搜索框。

**设计结论**：统一使用”飞行计划”概念，指代单次飞行。后端对应创建单次任务+自动生成同名单次计划。创建即提交（无草稿），表单数据本地暂存防止断网丢失。上传文件限定PDF格式。

**断网暂存机制**：

- 恢复网络后不自动提交，回到表单页让用户确认后手动点提交
- 关闭APP再打开，暂存数据仍在（持久化到本地存储）
- 如果暂存数据中的执飞时段已过期，提示用户”时段已过期，请修改后提交”

###### 2.2.2审批进度跟踪

查看所有我已申请的飞行计划，可查看审批状态。入口位于申报tab地图页的”我的计划”按钮。

**飞行计划状态流转**：

| 手机状态 | PC状态                 | 运营人操作                                      |
| -------- | ---------------------- | ----------------------------------------------- |
| 无       | 未提交                 | -----                                           |
| 审批中   | 审批中                 | 查看、撤回                                      |
| 审批通过 | 审批通过               | 查看、推延、 放飞申请(单次)、取消、变更（编辑） |
| 审批驳回 | 审批未通过             | 查看、编辑                                      |
| 待飞行   | 悬挂                   | 查看、推延、变更（编辑）、取消                  |
| 待飞行   | 预激活（长期无此状态） | 查看、变更（编辑）、推延、取消                  |
| 待飞行   | 非管控（长期无此状态） | 查看、取消                                      |
| 执飞中   | 管控（长期无此状态）   | 查看、取消                                      |
| 已完成   | 结束                   | 查看、                                          |
| 取消     | 取消                   | 查看                                            |

计划推延**：审批通过后、执飞前，飞手可申请推迟执飞时间：

- 最多允许推延2次
- 手机端暂不支持长期任务的创建。

#### 2.5我的

##### 2.5.1 信誉统计

显示，当前分数，分数解读，如何提高分数等操作

**积分规则**：

- 初始分：600（良好等级），企业与独立运营人统一标准
- 信誉分主体：挂在**企业/独立运营人**维度（非操控员个人）
- 积分等级：优秀 800+ / 良好 600-799 / 告警 400-599 / 限制 <400
- 分数下限：0（不为负数）
- 分数上限：暂不封顶
- 低于400降低飞行审批优先级，降低飞行申报频次；高于800提高飞行审批优先级

| 加分项         | 说明                                           |
| -------------- | ---------------------------------------------- |
| 航空器备案     | 主动备案航空器可+50积分，最多1次               |
| 操控员备案     | 主动备案操控员可+50积分，最多1次               |
| 申报飞行计划   | 主动申报飞行计划可+5积分/次                    |

| 扣分项         | 说明                                           | 触发条件 |
| -------------- | ---------------------------------------------- | -------- |
| 越界飞行       | 禁区、危险区、限制区、隔离空域侵入飞行（未来需+电子围栏越界）-30积分/次 | 告警产生后自动扣分 |
| 偏离航路 | 偏离航路-30/次 | 告警产生后自动扣分 |
| ~~超高飞行~~   | ~~超过适飞空域顶高飞行-30积分/次~~             | ~~告警产生后自动扣分~~ |
| 无飞行计划黑飞 | 未申报飞行计划的飞行-100积分/次                | 告警产生后自动扣分 |

**扣分逻辑**：告警产生后自动扣分，告警被忽略则不扣分（忽略=免责）。
