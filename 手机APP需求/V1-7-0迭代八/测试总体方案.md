已有 PC Web 系统 + 移动端页面原型/HTML 页面，因此测试重点不是传统 APK 安装测试，而是：

1. **移动端 Web/H5 页面适配测试**
2. **移动端浏览器访问测试**
3. **PC 系统与移动端功能联调测试**
4. **后续 Android APP 打包后的兼容性测试准备**

根据文档内容，移动端第一迭代规划为 Android APP，采用跨端框架实现，后续覆盖 iOS、鸿蒙、小程序、H5。当前移动端包含：

- 登录/找回密码
- 首页（消息通知 + AI 对话）
- 申报（地图 + 飞行计划创建）
- 资讯（法规、通知公告）
- 我的（信誉统计、关于我们、退出登录）

同时移动端存在大量依赖手机能力的功能：

- GPS定位
- 地图交互
- 文件上传
- 网络状态切换
- 本地缓存
- WebSocket实时通信
- 移动端权限管理

例如飞行计划申报要求：

- 基于 GPS 定位附近起降场
- GPS拒绝授权后需要降级为搜索模式
- 断网后本地暂存数据
- 恢复网络后人工确认提交

因此测试方案如下。

------

# 一、测试总体方案

## 1. 测试目标

验证低空空管自动化系统移动端：

| 测试方向   | 测试内容                               |
| ---------- | -------------------------------------- |
| 页面适配   | 不同手机尺寸、分辨率、系统版本显示正常 |
| 交互体验   | 点击、滑动、输入、返回操作正常         |
| 功能正确性 | 移动端业务流程符合需求                 |
| 数据一致性 | PC端与移动端数据同步                   |
| 网络适应   | 弱网、断网、恢复网络正常               |
| 权限能力   | GPS、文件、通知权限正常                |
| 性能       | 页面加载、地图渲染、响应速度           |
| 兼容性     | Android不同设备运行正常                |

        ↓
