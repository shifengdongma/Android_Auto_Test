## 三、关键技术实现

### 3.1 失败自动截图链路

```

  │
  ▼
pytest_runtest_makereport hook (conftest.py)
  │ when == "call" AND failed == True
  ▼
driver.save_screenshot(FAILED_{test}_{timestamp}.png)
  │
  ├──► allure.attach(png, "失败截图", ...)
  ├──► allure.attach(page_source, "页面源码", XML)
  └──► logger.error(f"测试失败: {test_name}")
```

### 3.3 定位器适配策略

```
每个元素定义 3 级定位器:

Level 1: resource-id (精确最快)
  (AppiumBy.ID, "com.dolphin.atc:id/login_btn")

Level 2: UiAutomator Selector (通用兜底)
  (AppiumBy.ANDROID_UIAUTOMATOR, 'new UiSelector().text("登录")')

Level 3: XPath (最后手段)
  (AppiumBy.XPATH, '//android.widget.Button[@text="登录"]')

Page Object 查找逻辑:
  if resource-id 存在:
      使用 resource-id
  else:
      回退到 UiAutomator Selector
```

### 3.4 WebView a11y 交互层（uni-app 真机校准，2026-08-14）

被测应用 `com.keda.atc` 为 uni-app 应用，页面内容渲染在 WebView 中，原生层仅暴露底部 Tab。
`utils/webview_a11y.py` 封装真机实测总结的交互规则，作为 Page Object 与 WebView 内容之间的适配层：

```
┌─────────────────────────────────────────────────────┐
│               utils/webview_a11y.py                  │
├─────────────────────────────────────────────────────┤
│ 交互规则 (真机 NOH-AN01, 1152x2376 实测):            │
│  1. a11y树在页面单次点击后约4秒构建; 反复点击会打断   │
│  2. 底部原生Tab坐标点击 (y=2290 避开手势导航区)       │
│  3. a11y树含后台堆叠页面节点 → is_displayed+位置过滤  │
│  4. webview输入框无法send_keys → 剪贴板+keyevent 279  │
│  5. 数据清空后首次进申报页弹EMUI权限 (允许本次使用)   │
├─────────────────────────────────────────────────────┤
│ 能力:                                               │
│  find_text / find_visible_by_text (min_y/max_y/exact)│
│  switch_tab / type_chinese / handle_emui_permission  │
│  pick_result (精确匹配, 排除首页卡片子串误判)         │
│  find_top_sheet_item (底部弹层列表首行定位)          │
│  element_center (元素中心坐标, 元素易stale坐标稳定)  │
└─────────────────────────────────────────────────────┘
```

**申报完整链路（已实测打通）：**

```
申报Tab → 起飞地/降落地/备降地 (搜索选择)
       → 出发时间 (15分钟档选择器)
       → 下一步 → 填写飞行计划页
       → 航空器 (底部弹层: 取消|选择航空器|确定 + 单选列表)
       → 操控员 (底部弹层: 取消|选择操控员|确定 + 单选列表)
       → 提交 → 确认弹窗("进入PC端飞行计划审批流程") → 确定
       → 我的计划页 (新计划置顶, 状态"已通过")

留空飞行分支 (已实测打通):
    申报Tab → 留空飞行 → 空域绘制页 (LoiterPage, 继承FlightPage)
       → 空域类型: 多边形 | 圆形 | 线缓冲区 (y≈1485-1539 点击切换)
         多边形/线缓冲区: 单击加点 + mobile: doubleClickGesture 双击结束
         圆形: mobile: dragGesture (duration=1500, 模拟长按后向外拖)
       → 空域名称 (剪贴板粘贴; 输入后必须关闭输入法键盘, 否则底部按钮被遮挡)
       → 修改出发时间 → 下一步 → 填写飞行计划 (复用常规流程, 提交确认弹窗)

我的计划分支 (已实测打通):
    申报Tab → 我的计划 → 计划列表页 (顶部"全部状态"筛选器 + 计划卡片)
```

**关键约定：**

- 选择结果项必须精确匹配（`text()`），后台首页卡片"新疆起降场1 → 新疆起降场2"
  会被 textContains 子串命中导致点错列表项
- 表单字段校验必须限定字段行区间（±70px），相邻字段值相同会互相误判
- 校验失败先做"已选中"确认再重试，值节点可能延迟进入 a11y 树

**环境注意：**

- 强杀测试/Appium 会话会导致设备端 `io.appium.uiautomator2.server` 进入 D 状态
  （内核级死锁，元素查询 240s 超时无响应）——会话必须正常退出，已死锁时重启设备恢复
- `single_run.py` 原子锁执行器：同一时刻仅一个实例驱动设备，防止并发 session 抢占
