## 三、关键技术实现

### 3.1 失败自动截图链路

```
测试失败
  │
  ▼
pytest_runtest_makereport hook (conftest.py)
  │ when == "call" AND failed == True
  ▼
driver.save_screenshot(FAILED_{test}_{timestamp}.png)
  │
  ├──► allure.attach(png, "失败截图", ...)
  ├──► allure.attach(page_source, "页面源码", XML)
  └──► logger.error(f"测试失败: {test_name}")
```

### 3.2 多设备并行架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Worker gw0 │     │  Worker gw1 │     │  Worker gw2 │
│  ────────── │     │  ────────── │     │  ────────── │
│  driver[0]  │     │  driver[1]  │     │  driver[2]  │
│  device[0]  │     │  device[1]  │     │  device[2]  │
│  systemPort │     │  systemPort │     │  systemPort │
│    8200     │     │    8201     │     │    8202     │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       └───────────────────┼───────────────────┘
                           │
              ┌────────────▼────────────┐
              │    Appium Server :4723  │
              │    (单实例多Session)     │
              └─────────────────────────┘
```

### 3.3 定位器适配策略

```
每个元素定义 3 级定位器:

Level 1: resource-id (精确最快)
  (AppiumBy.ID, "com.dolphin.atc:id/login_btn")

Level 2: UiAutomator Selector (通用兜底)
  (AppiumBy.ANDROID_UIAUTOMATOR, 'new UiSelector().text("登录")')

Level 3: XPath (最后手段)
  (AppiumBy.XPATH, '//android.widget.Button[@text="登录"]')

Page Object 查找逻辑:
  if resource-id 存在:
      使用 resource-id
  else:
      回退到 UiAutomator Selector
```

## 四、配置文件说明

### config.yaml 关键配置项

```yaml
# 环境切换 (环境变量 TEST_ENV 覆盖)
active_env: test

# Appium服务 (环境变量 APPIUM_SERVER_URL 覆盖)
appium:
  server_url: "http://127.0.0.1:4723"

# 超时配置
timeout:
  implicit_wait: 10    # 隐式等待
  explicit_wait: 15    # 显式等待 (推荐)

# 设备列表 (环境变量 DEVICE_INDEX 选择)
devices:
  - name: "Xiaomi14"
    platform_version: "14"
    automation_name: "UiAutomator2"
    app_package: "com.dolphin.atc"
    auto_grant_permissions: true

# iOS设备 (预留)
ios_devices:
  - name: "iPhone15_Simulator"
    automation_name: "XCUITest"

# 失败重试
retry:
  max_attempts: 3
  interval_ms: 1000
```

## 五、扩展点说明

### 5.1 iOS扩展

```
1. 安装驱动:
   appium driver install xcuitest

2. 配置文件:
   ios_devices:
     - bundle_id: "com.dolphin.atc"
       automation_name: "XCUITest"

3. 代码切换:
   driver_manager.get_driver(platform="iOS")

4. 新增Page (如需要):
   class LoginPageIOS(LoginPage):
       # 仅覆盖iOS特有的定位器
```

### 5.2 新业务模块扩展

```
1. pages/ 下新建 XXPage(BasePage)
2. 定义类常量: XX_BUTTON = (AppiumBy.ID, "...")
3. 实现方法: def do_xx(self): ...
4. tests/ 下新建 test_xx.py
5. pytest.ini 注册标记: xx: XX模块测试
6. run_tests.py 添加 --module xx 支持
```

### 5.3 CI/CD集成

```groovy
// Jenkins Pipeline 示例
stage('Mobile Test') {
    steps {
        sh '''
            source .venv/bin/activate
            appium --log-level error &
            sleep 5
            python run_tests.py --smoke --report
        '''
    }
    post {
        always {
            allure includeProperties: false,
                   results: [[path: 'reports/allure-results']]
        }
    }
}
```
