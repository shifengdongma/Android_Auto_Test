### 晚间：环境调试与问题修复

**遇到并解决的 7 个问题：**

| # | 问题 | 根因 | 解决方案 |
|---|------|------|---------|
| 1 | `ANDROID_HOME not exported` | Appium Server (Node.js) 找不到 SDK 路径 | 设置系统环境变量 + 代码自动检测 |
| 2 | `Unable to find device with OS 14` | 配置文件写死 Android 14，设备是 Android 16 | `_auto_fix_platform_version()` 自动修正 |
| 3 | `WRITE_SECURE_SETTINGS` 权限拒绝 | Android 14+ 禁止普通 ADB 修改系统设置 | Appium 启动加 `--relaxed-security` |
| 4 | `Cannot set device locale to zh_CN_CN` | language + locale 配置被错误拼接 | 移除 language/locale 配置项 |
| 5 | `--allow-insecure adb_shell` 格式错误 | Appium 3.6 改变了参数格式 | 改用 `--relaxed-security` |
| 6 | 设备断开连接 | 失败 Session 中断 ADB 连接 | `adb kill-server && adb start-server` |
| 7 | `No Chromedriver found for Chrome 150` | 手机 Chrome 版本过新 | 手动下载 ChromeDriver 150.0.7871.124 |
| 8 | `ERR_CONNECTION_CLOSED` | 自动导航到测试 URL 失败 | 改为 Session 创建后手动导航 |
