| 6 | 设备断开连接 | 失败 Session 中断 ADB 连接 | `adb kill-server && adb start-server` |
| 7 | `No Chromedriver found for Chrome 150` | 手机 Chrome 版本过新 | 手动下载 ChromeDriver 150.0.7871.124 |
| 8 | `ERR_CONNECTION_CLOSED` | 自动导航到测试 URL 失败 | 改为 Session 创建后手动导航 |

## 2026-08-07 — 框架能力扩展：APK 管理 / 生命周期 / 性能 / 弱网 / 稳定性

### 背景

原型框架已完成（browser 模式测 H5）。为正式 APK 就绪后的原生测试做准备，
按 6 项需求扩展框架：APK 安装卸载、App 生命周期、登录注册、截图日志、
性能采集、异常场景。

### 可行性分析结论

6 项需求全部可在 Python + Appium 框架中实现：

| 需求 | 结论 | 实现路径 |
|------|------|---------|
| APK 安装卸载 | ✅ 低风险 | 安装/卸载/版本检测已有；新增本地 APK 版本解析（aapt→pyaxmlparser→文件名三级回退）+ 自动对比升级 |
| App 生命周期 | ✅ | `am start -W` 测冷/热启动（Android 12+ LaunchState 自动识别）、HOME 切后台、activate_app 回前台 |
| 登录注册 | ✅ | 登录已有；注册按决策做**预留**（RegisterPage 模板 + 数据驱动，定位器待 APK 校准后自动激活） |
| 截图/日志 | ✅ | 截图已有；新增 logcat 按包名抓取 + 失败 hook 附带 logcat 现场 + ANR/崩溃分析 |
| 性能 | ✅（3注意点） | 启动耗时 `am start -W`；CPU `top`/`dumpsys cpuinfo`；内存 `TOTAL PSS`；电量 `dumpsys battery`（uiautomator2 无电量 API 必须走 ADB）；warn_only 阈值先建基线 |
| 异常 | ✅（限速需代理） | 开关级断网/飞行模式已实现；真机限速必须 PC 侧代理，`ThrottleController` 接口预留；monkey + ANR 检测 |

### 完成工作

**新增 5 个工具模块：**

| 模块 | 核心能力 |
|------|---------|
| `utils/apk_manager.py` | 本地 APK 扫描/版本解析（aapt 优先，本机已探测到 build-tools 36.0.0）/版本对比/安装升级卸载/一键就绪 |
| `utils/app_lifecycle.py` | 冷/热启动耗时测量（3轮统计中位数）、关闭、后台/回前台、状态报告 |
| `utils/performance.py` | CPU/内存/电量快照、定时采样线程、操作响应计时器、阈值校验（warn_only/strict）、CSV(utf-8-sig)+Allure |
| `utils/logcat.py` | LogcatCapture 按包名抓取+Allure attach；LogcatAnalyzer ANR/崩溃/被杀检测 |
| `utils/network_controller.py` | 开关级断网/飞行模式/网络恢复；ThrottleController 代理限速协议（预留） |

**ADBHelper 扩展 8 个方法**：`start_app_measured`（am start -W 解析）、`get_pid`/`is_process_alive`、`top_snapshot`/`cpuinfo_snapshot`/`meminfo_snapshot`/`battery_snapshot`、`run_monkey`（CRASH/ANR 解析）。

**conftest.py 扩展**：8 个新 fixture（adb/apk_manager/app_lifecycle/performance_collector/network_controller/require_native_mode/require_apk/weak_network）+ 3 个命令行参数（--perf-baseline/--perf-strict/--apk-path）+ 失败 hook 附带 logcat 现场。

**文档**：`docs/APK管理使用说明.md`、`docs/性能测试基线建立.md`、`docs/弱网测试方案.md` 3 篇新文档；README 更新（新模块结构/APK 工作流/性能基线）。

### 关键设计决策

1. **全部走 ADB 层**：性能/生命周期/APK 能力不依赖 driver，browser/native 双模式可用，driver 挂掉后仍能采集
2. **守卫机制**：`require_apk`/`require_native_mode` 用 skip 而非 fail，APK 未就绪时新用例自动跳过，仓库保持全绿
3. **弱网分层**：开关级断网立即实现，限速走 `ThrottleController` 协议预留（真机限速必须 PC 侧代理）
4. **性能阈值**：warn_only 默认不失败，`--perf-baseline` 建基线 3 次取中位回填 config

- ✅ 88 个用例全部收集成功（原 43 + 新 45），语法全通过
- ✅ 纯逻辑用例 7 个实测通过（版本对比 4 分支/阈值策略/CSV 编码/限速接口）
- ✅ 守卫机制实测：browser 模式 + 无 APK 时新用例自动 skip
- ⏳ 设备级验证（性能快照/生命周期/弱网/monkey）待设备连接后执行
